# Cab Eye — Double DQN Dialogue Recovery

> **Evidence Label**: `SIMULATED ENVIRONMENT — NOT VALIDATED ON BLIND USERS`  
> All transition dynamics, destination resolution probabilities, and user persistence scores are generated by a synthetic simulator reflecting the MatchGate failure modes in the Android client. This offline model establishes the mathematical foundation and interface contract prior to user study validation.

---

## 1. Overview & Architecture

The **Double DQN Dialogue Recovery System** adapts the recovery strategy of the Cab Eye voice-first cab-booking application when speech-to-text or destination resolution encounters ambiguity, low confidence, or missing candidate locations.

```
       [Speech Input / MatchGate Outcome]
                      │
                      ▼
            ┌───────────────────┐
            │  16-Feature State │
            └─────────┬─────────┘
                      │
                      ▼
         ┌─────────────────────────┐
         │ Valid-Action Mask (1×5) │
         └────────────┬────────────┘
                      │
                      ▼
        ┌───────────────────────────┐
        │ Q-Network: 16 → 64 → 64 → 5│
        └─────────────┬─────────────┘
                      │  Argmax over valid actions
                      ▼
          Selected Recovery Action
   (REPROMPT | ASK_MORE_INFO | CONFIRM | SAVED_PLACE | ESCAPES)
```

## 2. 16-Feature State Schema (Version 1)

Every element in the vector $\mathbf{s} \in [0, 1]^{16}$ is normalized and strictly bounded:

| Index | Feature Name | Range | Description |
|:-----:|:-------------|:-----:|:------------|
| `0` | `attempt_number_norm` | $[0.0, 1.0]$ | Attempt count clipped to $4$ and divided by $4.0$. |
| `1` | `speech_confidence` | $[0.0, 1.0]$ | ASR transcription confidence score. |
| `2` | `word_count_norm` | $[0.0, 1.0]$ | Spoken utterance word count clipped to $20$ and divided by $20.0$. |
| `3` | `match_gate_score` | $[0.0, 1.0]$ | Android MatchGate destination confidence score. |
| `4` | `gate_failed_no_match` | $\{0.0, 1.0\}$ | Flag: MatchGate failed because no candidate exceeded minimum score. |
| `5` | `gate_failed_multiple_matches` | $\{0.0, 1.0\}$ | Flag: Multiple ambiguous destination candidates matched. |
| `6` | `gate_failed_low_confidence` | $\{0.0, 1.0\}$ | Flag: Top candidate confidence is below safety confirmation threshold. |
| `7` | `gate_failed_candidate_missing` | $\{0.0, 1.0\}$ | Flag: Zero candidate places returned from geocoding. |
| `8` | `candidate_count_norm` | $[0.0, 1.0]$ | Candidate destination count clipped to $5$ and divided by $5.0$. |
| `9` | `has_saved_places` | $\{0.0, 1.0\}$ | Rider has registered saved destinations (Home/Work/Favorites). |
| `10` | `prev_action_reprompt` | $\{0.0, 1.0\}$ | One-hot: previous turn took action `REPROMPT`. |
| `11` | `prev_action_ask_more_info` | $\{0.0, 1.0\}$ | One-hot: previous turn took action `ASK_MORE_INFO`. |
| `12` | `prev_action_confirm_candidate` | $\{0.0, 1.0\}$ | One-hot: previous turn took action `CONFIRM_CANDIDATE`. |
| `13` | `prev_action_offer_saved_place` | $\{0.0, 1.0\}$ | One-hot: previous turn took action `OFFER_SAVED_PLACE`. |
| `14` | `prev_action_offer_escapes` | $\{0.0, 1.0\}$ | One-hot: previous turn took action `OFFER_ESCAPES`. |
| `15` | `consecutive_reprompts_norm`| $[0.0, 1.0]$ | Sequential reprompt count clipped to $3$ and divided by $3.0$. |

## 3. Canonical Actions & Safety Masking

Action index $a \in \{0, 1, 2, 3, 4\}$:

1. **`0: REPROMPT`**: Simple repetition request (*"Could you repeat your destination?"*). Masked if consecutive reprompts $\ge 2$.
2. **`1: ASK_MORE_INFO`**: Contextual disambiguation prompt (*"Which area or landmark?"*).
3. **`2: CONFIRM_CANDIDATE`**: Direct confirmation (*"Did you mean Central Station?"*). **Safety precondition**: Requires `candidate_count > 0` AND `match_gate_score >= 0.3`.
4. **`3: OFFER_SAVED_PLACE`**: Shortcut to saved place (*"Going to Home or Work?"*). **Precondition**: Requires `has_saved_places == True`.
5. **`4: OFFER_ESCAPES`**: Safety fallback (*"Would you like to call support or enter manually?"*). **Always valid**; mandatory when `attempt_number >= 3`.

Masking rule: If action $a$ is invalid, its Q-value is masked before argmax:
$$Q_{\text{masked}}(s, a) = \begin{cases} Q(s, a) & \text{if } \text{valid}(s, a) \\ -\infty & \text{otherwise} \end{cases}$$

## 4. Mathematical Double DQN Formulation

### Bellman Target with Action Decoupling
To avoid maximization bias, the online network selects the best valid next action, while the target network estimates its value:

$$a^* = \arg\max_{a' \in \mathcal{A}_{\text{valid}}(s')} Q(s', a'; \theta)$$
$$Y = r + \gamma (1 - d) Q(s', a^*; \theta^-)$$

where:
- $\theta$: parameters of the online Q-network
- $\theta^-$: parameters of the slowly-updated target network
- $d \in \{0, 1\}$: terminal state indicator
- $\gamma = 0.95$: discount factor

### Huber Loss (Smooth $L_1$)
$$L(\theta) = \frac{1}{B} \sum_{i=1}^B \text{Huber}(Y_i - Q(s_i, a_i; \theta))$$
$$\text{Huber}(\delta) = \begin{cases} \frac{1}{2}\delta^2 & \text{if } |\delta| \le 1.0 \\ |\delta| - \frac{1}{2} & \text{otherwise} \end{cases}$$

## 5. Reward Design

| Event | Scalar Reward | Terminal |
|:------|:-------------:|:--------:|
| Destination confirmed correctly | $+10.0$ | Yes |
| Incorrect destination confirmed (safety hazard) | $-20.0$ | Yes |
| Successful escape / human assistance accepted | $+5.0$ | Yes |
| Dialogue step penalty (latency friction) | $-1.0$ | No |
| Redundant reprompt penalty | $-2.0$ | No |
| Rider abandons dialogue | $-15.0$ | Yes |

## 6. CLI Usage

From the `ml/` directory:

```bash
# Run the 29-test unit test suite
python main.py test

# Train Double DQN offline for 1,000 episodes
python main.py train --episodes 1000 --seed 42

# Evaluate trained model against baselines (FixedLadder, RandomValid, AlwaysEscalate)
python main.py evaluate --checkpoint artifacts/best_checkpoint.pt

# Export PyTorch weights to JSON and verify Kotlin forward pass parity
python main.py export --checkpoint artifacts/best_checkpoint.pt --output artifacts/recovery_policy_v1.json

# Launch the live interactive dashboard & training service
python main.py serve --port 8000
```
